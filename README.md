# 🌌 Solar System

An animated solar system built using **HTML and CSS**. Explore the Sun and all eight planets as they revolve around the Sun in a beautiful space-themed environment.

## ✨ Features

- ☀️ Glowing Sun at the center
- 🪐 All eight planets of the Solar System
- 🌍 Animated planetary orbits using CSS
- 💫 Unique colors and glowing effects for each planet
- 💍 Saturn with CSS-created rings
- 🌌 Dark, space-inspired background
- 📱 Basic responsive styling for smaller screens
- ⚡ Lightweight project with no JavaScript dependencies

## 🛠️ Built With

- **HTML5** — Structure and content
- **CSS3** — Styling, animations, gradients, and planetary effects

## 🎨 CSS Animations

The planetary orbits are animated using CSS keyframes.

```css
@keyframes orbit {
    from {
        transform: rotate(0deg);
    }

    to {
        transform: rotate(360deg);
    }
}
```

Each planet has its own orbital animation duration, creating a dynamic solar system.
